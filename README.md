# MAXIO AI

A mobile-friendly, read-only Deriv market analysis dashboard.

## Deploy on Render
1. Create a GitHub repository named `maxio-ai`.
2. Upload `index.html` and this README to the repository root.
3. In Render, choose **New +** → **Static Site** (not Web Service).
4. Connect GitHub and select `maxio-ai`.
5. Set Build Command to blank / none, and Publish Directory to `.`.
6. Click **Create Static Site**. Render will provide a public `onrender.com` URL.

The dashboard reads public Deriv market data only. It does not connect to a trading account or place trades. Analysis scores are descriptive, not guaranteed win probabilities.
